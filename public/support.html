ADHD체력표시기 지원 안내

ADHD체력표시기 사용 중 문제가 생겼다면 아래 정보를 함께 정리하면 원인 파악에 도움이 됩니다.

  • 문제가 발생한 화면 이름
  • 문제가 생기기 직전의 동작
  • 브라우저 또는 기기 종류
  • 가능하다면 오류 화면 캡처

정식 문의 채널

운영 지원 채널은 GitHub 이슈 트래커를 사용합니다. 버그 제보, 화면 오류, 기능 요청은 아래 공개 페이지에서 접수할 수 있습니다.

  • https://github.com/estona815/focus-battery/issues
  • 새 이슈 등록에는 GitHub 로그인이 필요할 수 있습니다.

데이터 관련 안내

현재 앱 번들 기준으로 일정과 설정은 로컬 저장소 중심으로 보관됩니다. 사용자는 앱 설정의 “데이터 내보내기”와 “앱 데이터 초기화” 기능을 통해 자신의 데이터를 직접 관리할 수 있습니다.
